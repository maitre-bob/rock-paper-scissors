# Rock-Paper-Scissors Game (Pierre-Papier-Ciseaux)

## Description

This is a simple **Rock-Paper-Scissors game** implemented in JavaScript.  
The game is played in the browser console, where the user competes against the computer for **5 rounds**.  
It tracks the scores of both the player and the computer and announces the winner at the end.

---

## Features

- User-friendly **prompt input** for the player's choice.
- Random choice generation for the computer.
- **Case-insensitive input** (e.g., "Rock", "ROCK", "rock").
- **Score tracking** for both player and computer.
- **Announces winner** after each round and final winner after 5 rounds.
- Can be played multiple times after resetting the scores.

---

1. Open your **web browser** (Chrome, Firefox, Edge, etc.).
